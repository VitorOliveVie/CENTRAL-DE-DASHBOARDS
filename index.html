CENTRAL DE DASHBOARDS

DASHBOARD CCO Abrir Dash ↗
  • Troca prematura;
  • Relatórios (Estoques, ticket, posto fixo...);
  • Diagnósticos;
  • Parque de equipamentos;
  • Telas monitores.
DASHBOARD CHAMADOS Abrir Dash ↗
  • Acompanhamento dos chamados SDM;
  • Produtivo;
  • Monitoramento (Chamados SDM);
  • Tela monitores.
INSTALAÇÕES (IMPL. E DESMOB.) Abrir Dash ↗
  • Equipamentos Implantados e Desmobilizados;
  • Equipamentos implantados sem comunicação;
  • Tela monitores.
REPORT COMPRAS DE PAPEL Abrir Dash ↗
  • Acompanhamento das remessas de papel em atraso (normal e urgente);
  • KPI's de dias em atraso;
  • Comparativo das quantidades por dia.
DASHBOARD FINANCEIRO Abrir Dash ↗
  • Valores de emissão, planejado, faturado (MI, PI) e etc;
  • Insumos enviados e quantidades;
  • Relatórios (Faturamento global...);
  • Prévia de contratos (CAIXA).
DASHBOARD DISPONIBILIDADE Abrir Dash ↗
  • Disponibilidade das impressoras por mês (faturamento).
CTRC DE REMESSAS GPRINT Abrir Dash ↗
  • Acompanhamento da disponibilidade dos CTRCs das remessas de papel.
DASHBOARD DASA Abrir Dash ↗
  • Acompanhamento dos equipamentos sem bilhetagem para o cliente DASA.
DASHBOARD COPASA Abrir Dash ↗
  • Acompanhamento dos equipamentos sem bilhetagem para o cliente COPASA.
DASHBOARD REDE D'OR Abrir Dash ↗
  • Acompanhamento dos equipamentos sem bilhetagem para o cliente D'OR.
SITUAÇÃO IMOBILIZADO Abrir Dash ↗
  • Situação dos equipamentos imobilizados;
  • Equipamentos imobilizados não operacionais.
DASHBOARD RELATÓRIOS Abrir Dash ↗
  • Detalhamento do envio de insumos.
COLETA DE CONTADORES (APP) Abrir Dash ↗
  • Acompanhamento dos contadores inseridos via app.
REMESSAS PENDENTES Abrir Dash ↗
  • Remessas em atraso por tipo de insumo.
